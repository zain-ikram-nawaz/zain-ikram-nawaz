Built an interactive configurator where customers can customize van colors, materials, and components in real time.

* Van matching against real inventory
* Customer inquiry and lead pipeline
* Consultation booking with Google Calendar

* AWS infrastructure with EC2 and S3
* CI/CD deployment workflows
